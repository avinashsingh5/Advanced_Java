# Advanced Java Projects

This repository contains my coursework and projects completed during the Capgemini Training program as part of my Advanced Java studies at LPU.

## 🚀 Overview
The projects here focus on building robust backend systems, focusing on Database Management, ORM frameworks, and Unit Testing.

## 📂 Project Structure
* **Hibernate_Demo**: Introduction to Hibernate ORM and basic configuration.
* **Hibernate_Mapping**: Detailed implementation of Entity mappings.
* **JDBC**: Java Database Connectivity and SQL integration.
* **Java_Testing**: Unit testing practice using JUnit.
* **Week1Assesment**: Integrated assessment featuring Junit and Restaurant Management tasks.

## 🛠️ Skills Demonstrated
* **Frameworks:** Hibernate (ORM)
* **Database:** SQL, JDBC
* **Testing:** JUnit
* **Environment:** IntelliJ IDEA, Maven
